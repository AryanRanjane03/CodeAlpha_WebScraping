# CodeAlpha_WebScraping
# 📊 CodeAlpha Web Scraping & Data Analysis Project

## 📌 Project Overview
This project is part of the CodeAlpha Data Analytics Internship.  
It focuses on extracting data from a website, cleaning it, analyzing it, and visualizing insights using Python.

The dataset used is scraped from a books website and converted into a structured format for analysis.

---

## 🚀 Tasks Completed

### ✅ Task 1: Web Scraping
- Scraped book data from a public website
- Extracted title, price, rating, and availability
- Stored data in a structured CSV file using Python

### 📊 Task 2: Exploratory Data Analysis (EDA)
- Loaded dataset using pandas
- Performed data cleaning (price formatting)
- Analyzed ratings distribution
- Calculated statistical insights like average, max, and min price

### 📈 Task 3: Data Visualization
- Created bar chart for ratings distribution
- Created histogram for price distribution
- Visualized top 10 expensive books

---
